- Собственный шифрованный DNS: запросы идут по DNS-over-HTTPS, а не открытым текстом.
- Открытый DNS больше не выпускается мимо туннеля — провайдер не видит запрашиваемые имена.
- Профиль DNS для YouTube и Twitch больше не оставлял остальные имена без шифрования.
- Быстрее уходим с узла, у которого пропал обратный поток: обрыв длится секунды, а не минуты.
- Переподключение больше не возвращается на тот же неработающий узел.
- Фоновый подбор маскировочного домена закрепляется только после подтверждения трафиком.
- Первый запуск с Proton заметно быстрее: узлы опрашиваются разом, а не по очереди.
- Регистрация Proton больше не зависает: наконец используется встроенный обход блокировки API.
- MASQUE и Proton готовятся заранее в фоне, поэтому их выбор подключается сразу.
- Пока идёт регистрация, вместо «Подключить» показывается «Отключить»: процесс можно остановить.
- Пинг для Opera EU/US был завышен до трёх раз — теперь он соответствует действительности.
- При выбранных вручную EU или US кнопка следующего профиля убрана: она уводила в другой регион.
